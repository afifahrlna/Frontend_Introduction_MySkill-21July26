# HTML DAN SEMANTIC MARKUP (FRONTEND INTRODUCTION)

## Project Description
Membuat halaman perkenalan diri menggunakan HTML sebagai praktik dasar dari kelas *Frontend Introduction* bersama MySkill. Halaman ini disusun menggunakan berbagai elemen HTML, meliputi gambar profil, judul, paragraf deskripsi diri, daftar berurutan *(ordered list)* berisi alasan ingin belajar membuat *website*, serta tautan menuju profile Linkedln. *Website* ini disusun dengan prinsip *semantic markup* agar struktur halaman lebih rapi dan mudah dipahami.

## Insights
- Berhasil mengimplementasikan seluruh elemen HTML meliputi img, h1, dua h2, p, ol, dan a) dengan struktur yang mengikuti prinsip *Semantic Markup*.
- Struktur halaman disusun menggunakan pendekatan *Semantic Markup* dan *Grouping Element*, sehingga kode HTML lebih terorganisir, mudah dibaca dan sesuai dengan *best practice* pengembangan web.
